# Gerador da Declaração de Acessibilidade 

A Decisão de Execução (UE) 2018/1523 da Comissão, de 11 de outubro de 2018, cria o modelo de declaração de acessibilidade obrigatório para os sítios web e aplicações móveis dos organismos do setor público, em aplicação da Diretiva (UE) 2016/2102.

Em Portugal a transposição da Diretiva (UE) 2016/2102 foi transposta para o ordenamento jurídico nacional pelo DL nº 83/2018.

> Todos os sítios Web e aplicações móveis estão obrigadas a publicar a sua Declaração de Acessibilidade.

O Gerador da Declaração de Acessibilidade permite gerar a Declaração para sítios Web e para aplicações móveis segundo este modelo.

Entre no gerador, siga os passos e, no final, obtém a Declaração de Acessibilidade em HTML, pronta para copiar e colar no gestor de conteúdos do seu sítio Web. 

Nós damos a estrutura semântica do documento. O estilo é o do seu sítio web.
